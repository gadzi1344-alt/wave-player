# Wave — тёмный музыкальный плеер (Yandex Music API)

Структура:
```
wave-player/
├── index.html              # интерфейс (тёмная тема, плеер, «Моя волна»)
└── functions/
    └── api/[action].js     # серверные маршруты /api/search и /api/stream
```

## Деплой на Cloudflare Pages

1. Залейте папку `wave-player` в GitHub-репозиторий.
2. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
3. Build command: оставить пустым. Output directory: `/` (или `.`).
4. Settings → **Environment variables** → добавьте:
   - `YAM_TOKEN` = ваш OAuth-токен Яндекс Музыки (тип: Secret).
5. Deploy. Сайт будет на `https://<project>.pages.dev`.

## Получение токена

Токен получают через OAuth Яндекса (например, через сторонние утилиты «yandex music token»
или страницу авторизации Яндекса). Никогда не публикуйте токен в коде и в репозитории.

## Как это работает

- Браузер обращается к `/api/search?q=...` и `/api/stream?id=...` на вашем же домене.
- Функции Cloudflare добавляют токен и ходят в `api.music.yandex.net`, поэтому CORS и секреты не мешают.
- Для воспроизведения сервер получает подписанную ссылку на mp3 и отдает её плееру.

## Важно

- Яндекс не публикует официальное открытое API для треков. Используемые эндпоинты неофициальные
  и могут измениться без предупреждения.
- Использование должно соответствовать условиям Яндекс Музыки и авторским правам.
  Сайт подходит для личных экспериментов и учебы, а не для коммерческого распространения музыки.
- Если поиск или воспроизведение перестанут работать, первым делом проверьте токен и
  логи функций в Cloudflare (Pages → Functions → Logs).

## Локальный запуск

Самый простой способ — `npx wrangler pages dev .` из корня проекта
(нужна переменная `YAM_TOKEN` в `.dev.vars`: `YAM_TOKEN=ваш_токен`).
